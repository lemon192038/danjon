# ABYSS : ETERNAL FRONTIER

2D トップダウン型オンライン探索アクションRPG（Node.js 権威サーバー + Canvas ピクセルアートクライアント）。

## 起動

```bash
npm install
npm run build:data   # 参考資料(data/source)から 86武器種/8,600武器/8,600武器種スキル/1,000職業 を生成
npm start            # http://localhost:3000
```

`npm test` でデータ検証と全86武器種の戦闘シミュレーションを実行します。

## 構成

| パス | 役割 |
|---|---|
| `shared/data/weaponTypes.js` | 正式86武器種の戦闘定義（コンボ・判定・硬直・特殊アクション・回避・得意/苦手・属性・長短所） |
| `tools/gen/*` | データ駆動生成器：武器種スキル（名前→効果）、個別武器（レアリティ・固有スキル・特性・入手法）、1,000職業（40系統×25系譜）、ダンジョン/モンスター |
| `shared/gen/` | 生成物（git管理外・ビルド時生成） |
| `shared/formulas.js` / `skillText.js` | 能力計算・効果説明文（サーバー/クライアント共通） |
| `server/game/` | 権威サーバー：Zone(20Hz)、戦闘パイプライン、統一スキル実行器、78種の特殊アクション、モンスターAI(難易度別)、NPC冒険者(LOD)、パーティー、ダンジョンインスタンス、成長・報酬・クエスト |
| `client/` | 低解像度ピクセルレンダラー（ライティング・影・エフェクト）、入力（PC/タッチ）、全UI画面 |

## 主なシステム

- **武器**: 86種それぞれ固有のコンボ/形状/タイミング/特殊アクション。個別武器8,600種に固有スキル＋特性。77〜86（神話）は初期選択不可、ABYSSボス・特別クエスト等で入手。
- **スキル**: 武器種(熟練度で習得)・武器固有・レベル・職業の4系統を4スロットに自由編成。スキルLv成長、印/状態異常/CDリンク等の相互作用。
- **職業**: 1,000種（基本/応用/上級/特殊/希少/隠し）。固有パッシブ・アクティブ、熟練度ランク、解放条件、派生ツリー。武器装備制限なし（相性ボーナスのみ）。
- **ダンジョン**: 12ダンジョン×100階、10階ごとにバイオーム・レイアウト・ギミック・ボスが変化。EASY〜ABYSSの5難易度（ABYSSはAIの先読み・包囲・弱者狙い・階層呪い・変異）。
- **NPC冒険者**: 48人が独自に冒険・成長・買い物・交友。プレイヤー近傍では完全AI、それ以外は抽象シミュレーション。勧誘してパーティーに。
- **オンライン**: WebSocket、サーバー権威（入力のみ受信）、パーティー共同攻略、サーバー側セーブ。

## 都市・ギルド・生活（大型拡張）

- **6都市**（`shared/data/cities.js`）：ヘイヴン／交易港湾都市マリナ／王都セレスティア／鉄鋼都市ヴァルカンブルク／魔導学術都市アルカナリア／歓楽都市ルクスガルド。歴史・成立経緯・地理・気候・建築・産業・経済・政治・治安・階級構造・文化・ランドマーク・地区（富裕/商業/庶民/スラム）・施設・行事をデータで定義。`server/game/city.js` が地区（ボロノイ）・大通り・路地・橋・階段・建物・ランドマーク・装飾を生成。
- **建物内部**：全123棟の固有建物＋住宅が専用内部マップ（テンプレート27種）を持ち、扉で出入り。営業時間あり。内部も他プレイヤーと共有。
- **ギルド60組織**（`shared/data/guilds.js`）：加入条件・ランク・日替わり依頼（討伐/踏破/ボス/採集/都市間配送/鍛造/寄付/闘技/訪問）・専用ショップ・評判（協力/競争/敵対関係に波及）・固有イベント。
- **生活**：ゲーム内時計（1日=48分）・都市別天候・市民約700人の生活スケジュール（勤務/昼食/余暇/帰宅、天候で行動変化、LOD）。会話と個人的な頼みごと。
- **経済**：交易品9種の地域相場と物流（隊商・船便・鉄道・飛空艇）、都市間交通、街内乗合、不動産（6段階・購入/賃貸）、自宅（保管庫・家具・武具展示・休息・料理）、店舗経営（陳列・値付け・従業員・NPC客）、銀行、カジノ（ゲーム内通貨のみ）、闘技場、闇市、情報屋、仕立て屋、鍛造、採集。
- **物語**：都市ごとの連続クエストと分岐選択。最初に選んだプレイヤーの選択がワールド全体の情勢（物価・治安・闇市など）を変える。

## デプロイ (Render)

セーブは `SUPABASE_URL` と `SUPABASE_SERVICE_ROLE_KEY` が設定されていれば Supabase（`aef_accounts` / `aef_chars` / `aef_world` テーブル、RLS有効・service role専用）に、未設定ならローカルの `DATA_DIR` に保存されます。サーバーはメモリキャッシュで動作し、変更は2秒ごとに非同期で書き込まれます。

## スラム探索・脱出システム
- 各都市のスラム地区「スラム深部への入口」から潜入。6地域（危険度1〜5）、4層構造（地下・地上・中層・屋上）を梯子で行き来。
- 探索ごとのシードで可変区画（臨時通路・隠し部屋・封鎖・物資配置・異変イベント）を生成し、到達性を検証。固定区画（主要通路・常設出口）は不変。
- 物資を調べてバッグに収集（重量制限・職業補正）。保険ポーチ2枠は倒れても失わない。制限時間25分、条件付き脱出地点（ヒューズ・通行料・夜・鍵・時刻・勢力評判）。
- 失敗ルール：死亡時はバッグを失う（遺体コンテナとして他者が回収可能）。危険度4以上のみ未保険の装備武器を失う（予備武器は必ず残る）。切断時は生存中なら復帰、装備は失わない。危険度3以上はPvPvE。
- 闇市：地域別の需給・履歴・上下限付きの変動相場（将来価格は表示しない）。出所（正規・スラム・遺跡・非合法・不明・鑑定済）により売却経路が変わり、質屋・鑑定屋・故買屋で洗浄可能。
- 隠れ家：購入・勢力譲渡・権利書・紹介で入手。5段階拡張、11種の設備（分解・闇鍛冶・錬金・情報端末・地図管理台・隠し収納・警備など）。襲撃は抽象イベントで、失うのは保管庫の安価品の最大10%のみ。
