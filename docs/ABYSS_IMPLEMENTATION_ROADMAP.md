# ABYSS 実装ロードマップ

方針：各フェーズは「実際に動作する機能」を完成させてから次へ進む。既存機能は維持し、各フェーズ完了時に `npm test`（全スイート）＋ブラウザ（PC・iPad）で確認し、Render へデプロイする。
凡例：✅完了 ／ 🔶進行中 ／ ⬜未着手 ／ ⛔判断待ち

## PHASE 7（前半）の成果

- 決闘システム（server/game/duel.js）：対戦相手はプレイヤーと同じ戦闘処理を使う戦士（コンボ・スキル・回避・固有アクション・強攻撃）。AIは「見えている攻撃の予備動作」に反応して回避・パリィし、相手の過去の戦い方（武器種・近接/遠距離・回避率・スキル使用）を記録して次回の戦術（間合い・詰め方・フェイント）を変える。入力の先読みはしない。決闘では一撃で最大HPの35%を超えるダメージを受けない
- 放浪する最強の剣士：レイヴァン・クロイツが世界の街道・森・荒野・遺跡を約1時間ごとに巡回。近づくと待っていてくれる。決闘は専用の闘技場。3つの武器種で勝つと隠し試練「無銘の極致」（本気の再戦）→ 称号「剣聖に認められし者」「無銘を超えし者」、「無銘・天断（レプリカ）」（会心時に会心ダメージ上昇のアーティファクト。オリジナルは入手不可）、剣理の探究者の解放
- 仮面の武闘祭：王都アルセリアの酒場そばの仮面の案内人。資格（Lv30）→仮面→登録（1,000G・1日1回）→予選3→本戦2→決勝（仮面の王）。参加者の名前・職業は伏せられ、外見は仮面と大会装束に統一（能力はそのまま）。本戦から特殊参加者（王国騎士団長・レイヴァン・元大罪司教・未発見職業の冒険者・伝説武器の所持者）が紛れ、倒すと正体が明かされる。優勝3回＋正体の記録3つで「素顔の王」→ 闘技王の解放
- 不具合修正：決闘・闘技場で吹き飛ばされて出口マットに乗ると試合が終わってしまう問題（試合中は出口が無効）
- 参加者の補充は現在すべてNPC（プレイヤー同士の大会マッチングは後続）
- テスト：test/duels.test.mjs

## PHASE 7（後半）の成果

## 既存機能を壊さないための対策

1. 既存データ（武器種・武器・職業・スキル・都市・ギルド・キャラクター）の ID と名称は変更しない。新規は別レジストリに追加する
2. キャラクターデータは追加フィールドのみ（`migrate()` で既定値を補う）。旧セーブはそのまま読める
3. 世界状態（aef_world）は既存キー（npcs, econ, market）を維持し、新規は `events` キーに保存
4. 新システムは既存のフック（onMonsterKilled, onFloorReached, guilds.event, econ.storyEvent）に「追加で」接続し、既存処理の順序や結果を変えない
5. 各フェーズで既存5テストスイートを必ず通し、新システムには専用テストを追加する
6. 報酬・アイテム・通貨・職業解放は全てサーバー側で条件検証し、イベント報酬は報酬キー単位で一度だけ付与する
7. 大規模変更は小さなコミットに分け、各コミットでデプロイを確認する
