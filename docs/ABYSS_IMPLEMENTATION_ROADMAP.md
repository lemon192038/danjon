## PHASE 1 の成果（完了）

- `server/game/events.js` EventEngine：開始／段階進行（前進のみ）／完了（結末を定義と照合）／前提イベント／発生条件評価（level・職業・称号・所持品・イベント段階・世界状態・フラグ・発見地・時間帯・武器熟練度・到達階、all/any/not）

## 既存機能を壊さないための対策

1. 既存データ（武器種・武器・職業・スキル・都市・ギルド・キャラクター）の ID と名称は変更しない。新規は別レジストリに追加する
2. キャラクターデータは追加フィールドのみ（`migrate()` で既定値を補う）。旧セーブはそのまま読める
3. 世界状態（aef_world）は既存キー（npcs, econ, market）を維持し、新規は `events` キーに保存
4. 新システムは既存のフック（onMonsterKilled, onFloorReached, guilds.event, econ.storyEvent）に「追加で」接続し、既存処理の順序や結果を変えない
5. 各フェーズで既存5テストスイートを必ず通し、新システムには専用テストを追加する
6. 報酬・アイテム・通貨・職業解放は全てサーバー側で条件検証し、イベント報酬は報酬キー単位で一度だけ付与する
7. 大規模変更は小さなコミットに分け、各コミットでデプロイを確認する
