## PHASE 1 の成果（完了）

- `server/game/events.js` EventEngine：開始／段階進行（前進のみ）／完了（結末を定義と照合）／前提イベント／発生条件評価（level・職業・称号・所持品・イベント段階・世界状態・フラグ・発見地・時間帯・武器熟練度・到達階、all/any/not）
- 報酬は (キャラ, イベント, 報酬キー) で一度だけ付与。再挑戦報酬は挑戦回ごとのキー
- 世界共有状態（dormant→omen→active→resolved、発生回数、フラグ、世界の歴史）を aef_world の `events` に永続化。個人状態はキャラクターの `events`（進行・報酬取得・記録・発見地）
- ログアウト中の簡略シミュレーション基盤（経過時間を最大72時間で一括処理）
- 隠し領域の発見フラグ
- 既存コンテンツ（都市の物語5本・スラム探索・闘技場・ダンジョンボス）をジャーナルと履歴に接続（既存の挙動は変更なし）
- クライアント：「記録」画面（イベント一覧の検索・絞り込み・並び替え、段階表示、個人の記録、世界の歴史、称号・発見地）。PC・iPad 確認済み
- テスト：test/events.test.mjs（不正な段階・結末・二重付与・前提・条件・世界状態・永続化・ジャーナル・物語連携）

## PHASE 3a の成果

- グレイヴェル：アルセリア南西に隣接する都市（徒歩・馬車）。灰色市場、七組織の拠点、無名の地下闘技場、黒炉工房、エドガーの家、地下街への入口

- 世界共有シミュレーション（server/game/orgs.js）：ログアウト中も最大72時間分を一括進行。縄張りの増減、抗争（敵対組織同士）、首領交代（不満や衰退で幹部が継ぐ・歴代首領を記録）、同盟の変化、噂
- プレイヤー：組織ごとの評判（地下街で敵視されるかが変わる）、拠点での仕事（敵対組織の構成員撃破・品物の納品・上納金）、加入（敵対組織の評判が下がる）

## ユーザー追加要望（2026-11-25 実装）

- 不具合修正：ダンジョンの階段・出口・魔物・宝箱が壁で閉ざされた小部屋に生成されることがあった（2,400階中24階）。フィールドで魔物が木や採集ポイントの間に挟まって出現した。到着地点からの歩行距離と、周囲が開けた地面で配置するよう修正。回帰テスト test/mapgen.test.mjs
- 特性変更：街の祭壇で特性変更チケットを1枚使い、武器の特性を1つ選んでランダムな別特性に変更（同レア度帯・既存特性と重複なし・武器個体ごとに保存）。HARD以上の50階以降のボスで2枚確定
- アーティファクト：HARD以上のダンジョンボスから10%で「条件の核」か「効果の核」。鍛冶屋で1つずつ組み合わせて作成し、2枠に装備。条件7種（スキル使用時は5重まで・会心時・撃破時・印破壊時・パリィ/反撃成功時・召喚物死亡時・瀕死時）。厳しい条件ほど効果大、属性ダメージは攻撃力などより%が大きい。ダンジョンごとに付く効果が異なり、ボスの階層と難易度で効果量と効果時間が伸びる
- お気に入りと一括売却：武器などに★お気に入り。所持品画面（街）でレア度を選んで、装備中・お気に入り以外の武器を一括売却

## 既存機能を壊さないための対策

1. 既存データ（武器種・武器・職業・スキル・都市・ギルド・キャラクター）の ID と名称は変更しない。新規は別レジストリに追加する
2. キャラクターデータは追加フィールドのみ（`migrate()` で既定値を補う）。旧セーブはそのまま読める
3. 世界状態（aef_world）は既存キー（npcs, econ, market）を維持し、新規は `events` キーに保存
4. 新システムは既存のフック（onMonsterKilled, onFloorReached, guilds.event, econ.storyEvent）に「追加で」接続し、既存処理の順序や結果を変えない
5. 各フェーズで既存5テストスイートを必ず通し、新システムには専用テストを追加する
6. 報酬・アイテム・通貨・職業解放は全てサーバー側で条件検証し、イベント報酬は報酬キー単位で一度だけ付与する
7. 大規模変更は小さなコミットに分け、各コミットでデプロイを確認する
