# ABYSS 作業状態（WEAPON IDENTITY 指示書）

最終更新: 2026-11-27

## 目的
武器の名前やステータス画面を見なくても、戦闘中の外見・攻撃方法・特殊能力・魔法陣から、どの武器を使っているか判別できるようにする。
86の基本武器種は統合・削除・名称変更しない。既存の攻撃力・会心・攻速・入手方法は変更しない（武器の構造による長所・短所は `ident.mods` の小さな補正として別に持つ）。

## 仕組み（データ駆動）
| 層 | ファイル | 内容 |
|---|---|---|
| 武器の個性データ | `shared/data/identity.js` | 武器種ごとの「型」（外見 look / 形状 sil / 固有機構 mech / 能力 / 戦闘スタイル / 長所 / 短所 / 補正 / 固有スキル） |
| 召喚体 | `shared/data/identity.js` `SUMMON_BODIES` | 人形6種・精霊6種。HP・大きさ・AI・移動速度・攻撃方法・クールダウン・被ダメ軽減・見た目が個別 |
| 魔法陣ライブラリ | `shared/data/circles.js` | 45模様 × 15属性 = 675種の魔法陣レコード（designFamily, geometricPattern, symbolSet, attribute, weaponTheme, animationPattern, rotationSpeed, scale, colorParameters, layerCount, activationSequence） |
| 生成 | `tools/gen/weapons.mjs` `applyIdentity` | 各武器に `ident`（weaponId 相当の model / variant / silhouette / look / mechanic / ability / style / pros / cons / mods / anim / fx / sound）を付与し、固有スキルを型の技（name, cat, eff, target, limit, activation, actual, circle, circle2, anim, fx, sound）に置き換える |
| サーバ処理 | `server/game/mechanics.js` | 通常攻撃の前後処理・命中時処理・人形と精霊のAI・指揮スキル（`t: 'cmd'`）。結果はすべてサーバが決定 |
| クライアント表示 | `client/js/identity.js` `client/js/circles.js` | 型ごとの武器の見た目、人形・精霊の体、装備者の周りの表示（浮遊刃・魔力核・音符・精霊）、魔法陣の描画とアニメーション |

型の割り当て: 武器名のキーワードで決め、該当しない場合は武器の番号で均等に割り振る（同じ武器種の100本が全型を使う）。

操偶杖の指示書の例は実装済み:
- 十傀・一斉光砲: 主に近い順に最大10体の人形が、それぞれ最も近い敵へ光線。発射まで人形は静止し、消えた人形は除外。
- 傀儡陣・鉄壁布陣: 人形が主の周りに布陣して挑発し、主の被ダメージを軽減（その間、人形は攻撃しない）。
- 百傀・追撃連鎖: 人形が順に追撃し、外れると連鎖が止まる。
- 傀儡転位・身代わり: 最も遠い人形と位置を入れ替え、人形が挑発と障壁を得る。
