# ABYSS 作業状態（WEAPON IDENTITY 指示書）

最終更新: 2026-11-27

## 目的
武器の名前やステータス画面を見なくても、戦闘中の外見・攻撃方法・特殊能力・魔法陣から、どの武器を使っているか判別できるようにする。
86の基本武器種は統合・削除・名称変更しない。既存の攻撃力・会心・攻速・入手方法は変更しない（武器の構造による長所・短所は `ident.mods` の小さな補正として別に持つ）。

## 仕組み（データ駆動）
| 層 | ファイル | 内容 |
|---|---|---|
| 武器の個性データ | `shared/data/identity.js` | 武器種ごとの「型」（外見 look / 形状 sil / 固有機構 mech / 能力 / 戦闘スタイル / 長所 / 短所 / 補正 / 固有スキル） |
| 召喚体 | `shared/data/identity.js` `SUMMON_BODIES` | 人形6種・精霊6種。HP・大きさ・AI・移動速度・攻撃方法・クールダウン・被ダメ軽減・見た目が個別 |
| 魔法陣ライブラリ | `shared/data/circles.js` | 45模様 × 15属性 = 675種の魔法陣レコード（designFamily, geometricPattern, symbolSet, attribute, weaponTheme, animationPattern, rotationSpeed, scale, colorParameters, layerCount, activationSequence） |
| 生成 | `tools/gen/weapons.mjs` `applyIdentity` | 各武器に `ident`（weaponId 相当の model / variant / silhouette / look / mechanic / ability / style / pros / cons / mods / anim / fx / sound）を付与し、固有スキルを型の技（name, cat, eff, target, limit, activation, actual, circle, circle2, anim, fx, sound）に置き換える |
| サーバ処理 | `server/game/mechanics.js` | 通常攻撃の前後処理・命中時処理・人形と精霊のAI・指揮スキル（`t: 'cmd'`）。結果はすべてサーバが決定 |
| クライアント表示 | `client/js/identity.js` `client/js/circles.js` | 型ごとの武器の見た目、人形・精霊の体、装備者の周りの表示（浮遊刃・魔力核・音符・精霊）、魔法陣の描画とアニメーション |

型の割り当て: 武器名のキーワードで決め、該当しない場合は武器の番号で均等に割り振る（同じ武器種の100本が全型を使う）。

第2波で追加したサーバの機構:
- 吸命: 攻撃のたびにHPを吸収する。
- 状態異常付与: 炎上・出血・毒・防御低下・呪いを命中時に与える。
- 突進: 攻撃のたびに踏み込む。
- 残像: 同じ攻撃をもう一度遅れて出す。
- 加速: 攻撃を続けるほど速くなる。
- 矢の雨: 数回ごとに降らせる。
- 転移: 締めで敵の背後へ回る。
- 跳弾・往復弾。
- 会心・被ダメ軽減の構造補正。

分割・連撃・残像の機構は、近接にも射撃にも同じように働きます。

## 攻撃モーションと効果音（完了）
- `client/js/motion.js`: 全82種の型キーそれぞれに、攻撃モーションと効果音を設定した。
- モーションは15種類:
  - 薙ぎ払い・振り下ろし・溜め振り・突き・連続突き・乱れ斬り・回転・手の中で回す・鞭のしなり。
  - 掲げる・踏み込み叩きつけ・浮遊・反動・弓を引く・二連突き。
  - 型によっては、残像（数フレーム前の武器を半透明で重ねる）・属性の光・幻影を加える。
- 効果音はWebAudioの合成音（素材ファイルなし）:
  - モーションの基本音に、型の材質・属性の音（炎・氷・雷・魔力・呪い・吸命・聖・金属・残像・核）を重ねる。
  - 楽器武器は武器ごとに違う音程を鳴らす。
  - 固有スキルは型の音に詠唱音を加え、機構の発動（衝撃波・核の炸裂・地割れ・旋律・精霊・転移など）にもそれぞれ音を付けた。
  - 近くの他プレイヤーの攻撃音も小さく聞こえる（音数は制限）。

# 大型アップデート：変身系武器種20種（実装済み）
- 武器種は合計106種。既存の86種はそのまま（削除・統合・改名なし）、新しい20種（ID 87〜106）を「変身系」カテゴリとして追加。キャラクターメイキングの武器種選択にも「変身系」タブが出る。
- データ：`shared/data/morph.js`（20種の資源・姿・攻撃部品・形態別スキル・変身因子・機体パーツ）、`tools/gen/morph.mjs`（武器名100・武器種スキル名100・形態別スキル6を生成）。武器・スキル・熟練度・強化・図鑑は既存の仕組みをそのまま使用。
- サーバ：`server/game/morph.js`。通常／部分／半／完全の4段階。段階ごとに攻撃（コンボ）・強攻撃（締め技）・回避の種類・移動速度・当たり判定の大きさ・飛行・被ダメージ軽減などが変わる。
  - 資源は武器種ごとに名前と増減が違う（本能・竜力・生体エネルギー・親和・深淵圧・変異・魔神・属性エネルギー・影・終末・機体エネルギー・共鳴・流動・星核・武装・神性・霊気・夢幻・時流・万象）。終末化身だけは完全変身中に資源が溜まり、体力を少しずつ消費する。
  - 操作：特殊（右クリック／◆）を押す＝次の段階、完全変身中に押す＝姿ごとの固有技、長押し＝解除。強攻撃（R／⚡）は今の姿の締め技。
  - 部分変身は維持し続けられる（ログアウトしても維持）。半変身は時間制、完全変身は資源を消費して維持する（どちらもログアウトで解除）。
  - 姿（獣種・竜種など）は武器種の熟練度0／20／40／60…で解放。完全変身で使うほど成長（最大Lv10）。武器の強化値も変身中の威力に反映。
  - 万象転生：他の変身系武器種の熟練度10で因子を解放（ボスからもまれに入手）。頭・腕・脚・背・胴の5枠を組み合わせ、3枠まで保存できる。機神装は腕・脚・コアのパーツを交換。
  - 姿ごとの仕組み：熊・甲虫などは怯まない、反射結晶は飛び道具を跳ね返す、フェニックスは一度蘇る、時空変生は巻き戻し、夢幻は回避で分身、狼は追跡、裁定の神格は呪われた敵に強い、共鳴晶は命中ごとに強まる、流体は回避の無敵時間が長い、深海化身は水中と雨で強化、影獣化は夜と暗所で資源が溜まる（日中は減りやすい）。
  - 形態別スキル：通常・部分・半・完全の各段階専用、常時発動、必殺技（完全変身中に資源を消費）。
- 表示（2D）：`client/js/morphs.js`。部分変身・半変身は人の姿に部位を重ね、完全変身は34種類の体型（四足獣・熊・竜・蛇竜・昆虫・蜘蛛・蟷螂・蜂・鳥・馬・タコ・イカ・深海魚・クラゲ・異形・魔神・精霊・霊・結晶・流体・星・機体など）。同じ体型の姿は装飾で描き分けた。
  - 動き：待機・歩行・攻撃・回避・被弾・ジャンプ・飛行を、プログラムで描くドット絵として実装。変身の開始・完了・解除は粒子と拡大・クロスフェード（約0.45秒）。
  - HUD：資源ゲージ（押すと変身パネル）。変身パネル：段階・資源の増え方・姿の一覧と攻撃・形態別スキル・パーツ・因子。PCとタッチの両方で操作できる。
- テスト：`test/morph.test.mjs`。全20種で通常→部分→半→完全・攻撃・当たり判定・形態別スキル・必殺・固有技・解除・資源を確認。種族の解放、因子、パーツも確認。
- 未対応・制約：
  - 姿の絵は手描きのフレーム画像ではなく、プログラムで描くドット絵。
  - 「落下・着地」は既存の空中状態の表示を流用。
  - 変身先の系統はキャラクターメイキングでは選ばず、熟練度による解放後にゲーム内で選ぶ（C-61）。

# 新職業：時律投刃士（実装済み）
- 固有職 `ev_chrono`（Lv20で転職可能）。転職すると専用武器「銀の投げナイフ」を受け取り、時律投刃士以外は装備できない。
- 通常攻撃：銀刃連舞の5段（1→2→3→2本＋移動→周囲8本）。攻撃方向は近くの敵（ロックオン優先）へ自動で決まるが、キャラクターの向きは変えない。各段で前へ移動する。
- スタイル：ラピッド／ピアスを特殊ボタンかHUDのボタンで切り替え。数値は指示書どおり。
  - ラピッド：攻撃速度+25%、威力90%、撃破ごとに攻撃速度+5%（最大3段、5秒で解除）。
  - ピアス：攻撃速度−10%、威力135%、3体まで貫通、同じ敵への連続命中で+5%（最大+25%）。
  - タイムラグ：時刻崩壊中だけ選べる。
- 倍率は次をそれぞれ独立に一度ずつ掛ける：スタイル、連続命中、コンボ倍率（表どおり・4秒）、直近0.7秒の敵ごとの命中本数倍率（表どおり）、時刻崩壊+30%、側面・背面補正。
- 時刻印：敵ごとに最大100。100になると次のスキルが強化され、使うと消費する。
- 時刻崩壊ゲージ：通常+2、スキル+8、ジャストパリィ+12、コンボの締め+10、弱点+5。発動すると6秒間、攻撃速度+50%、ダメージ+30%、クールダウン2倍速、時間刃、タイムラグスタイルが使える。終了時に元のスタイルへ戻り、設置中のナイフは発射される。
- スキル：
  - ミスディレクション（転職で得る職業スキル）。
  - プライベートスクウェア：半径8m・3秒。通常の敵と敵の飛び道具は停止、ボスは約20%の速度。プレイヤーには一切効かない。
  - ルナクロック：時間共鳴あり。
  - 殺人ドール：40本。
  - 時刻崩壊は銀の投げナイフの固有スキル枠。
- 時間停止中とタイムラグスタイルでは、攻撃・スキルのナイフが空間に設置される（上限なし、ワールド座標で固定）。停止が解けると一斉発射し、1本ずつ独立に命中判定する。負荷測定では5000本で発射2.6ms、1ティック約2ms。
- テスト：`test/chrono.test.mjs`（5段・スタイル・各倍率の独立・時刻印・ゲージ・6秒・時間停止・設置100本と一斉発射・ルナクロック・殺人ドール40本）。
- 制約：本作には部位破壊の仕組みがないため、部位のロックオンはロックオン対象の優先で、ボス弱点は属性弱点への命中で代替した（C-63）。

# プレイヤー同士の決闘（実装済み）
- 決闘パネル（メニューの「決闘」）で、近くのプレイヤーに1本勝負か3本勝負を申し込む。相手が受けると専用の決闘場へ移動する。
- 決闘のルール：
  - 3秒のカウントダウンの後に開始。互いに別のチームになり、全ての武器・スキル・変身・職業の仕組みが使える。
  - 体力が尽きても倒れず、その戦の負けになる。1回の攻撃は最大HPの25%まで。1戦2分で、時間切れは残り体力の多い方の勝ち。
  - 終わると元の場所・元の体力に戻る。装備やお金は一切賭けない。
- 結果はEloレートと勝敗に記録し、ランキングと最近の決闘を表示する。降参・切断・決闘場からの離脱は相手の勝ちになる。
- テスト：`test/pvp.test.mjs`。ブラウザでも2人で申し込み・受諾・戦闘・降参まで確認した。
