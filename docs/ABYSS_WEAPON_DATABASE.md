# ABYSS 武器データベース

> 自動生成：`node tools/docs/gen-db-docs.mjs`（データ元：shared/data/weaponTypes.js, shared/gen/types/*.json）。手で編集しないこと。

## 概要

- 正式武器種：**86種**（固定。統合・削除・改名禁止）
- キャラクター作成時に選択可能：76種（77〜86の神話・超常系は不可）
- 武器：各武器種100本 × 86 = **8600本**（全て固有ID・性能・特性・入手方法・固有スキル付き）
- 武器種スキル：各武器種100（熟練度1〜100で順に習得）
- 弓（44）とクロスボウ（45「クロスボウ（弩）」）は別武器種。「弩」はクロスボウの別名として45に統合済み（正式リスト通り）

## 武器の共通データ項目（実装済み）

| 項目 | 実装 |
|---|---|
| 固有ID | `<武器種>_<001-100>` |
| 名称 | 企画資料の武器名リスト（data/source/weapon_names.md） |
| レアリティ | 1〜6（神話系は4〜6） |
| 基本性能 | 攻撃力・装備Lv・攻撃速度・会心・ステータス補正 |
| 属性 | 武器種の属性傾向から決定 |
| 特殊特性 | 25種の特性（貫通・吸血・会心強化など） |
| 固有スキル | 武器1本ごとに1つ（31種の効果シグネチャ） |
| 入手方法 | 店売り／ドロップ／宝箱／ボス／クエスト（階層・難易度条件付き） |
| 強化 | +0〜+20（強化鉱石・ゴールド）、+10以上で強化先へ進化 |
| 外観 | 武器種ごとのピクセルスプライト＋レアリティ色 |
