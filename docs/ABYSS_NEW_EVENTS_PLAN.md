# 新規30イベント 設計・実装計画（NEW WORLD EVENTS — 30 EVENT EXPANSION）

指示書「NEW WORLD EVENTS — 30 EVENT EXPANSION」の PHASE A（設計・既存システム確認）の結果。実装は PART Ⅶ の順（C → D → E → F → G）で段階的に行う。

## 既存システムの確認（再利用するもの）

| 必要な仕組み | 既存の実装 | 方針 |
|---|---|---|
| イベント管理・進行保存・履歴 | `server/game/events.js`（EventEngine：start/advance/complete/grant/record/history/世界状態/オフライン簡易シミュレーション） | そのまま使う。30件を台帳 `shared/data/events.js`（グループ `nx`）に登録 |

| NPCの日常行動（家・仕事・食事・休息・天候） | `server/game/life.js`（市民の時間割・抽象移動・実体化） | イベントNPCを「物語市民」として注入し、時間割をイベント状態で切り替える（`server/game/storynpc.js`） |

| 経済・物価・交易路 | `server/game/econ.js`（都市ごとの供給・交易路・ニュース） | 商人・交易路・商業祭・復興で流用 |

| 世界共有の状態 | `events.w.flags` / `events.w.ev`（Supabase `aef_world` に保存） | 村・国家・交易路・商人位置などを保存 |

## 重複の扱い
- 「旅を続ける商人」と第11章の「名もなき商人」は同じ題材のため、新イベント側で実装し、台帳の名もなき商人は統合扱いにする（二重実装しない）。
- その他の第11章イベントは、新イベントと題材が近くても役割が異なるため、関連（links）としてつなぐ。

## 進捗

### PHASE A・B・C（完了）
- 30件を台帳（グループ `nx`）に登録。実装済みは「live」、未実装は「planned」と表示される
- 共通システムの拡張：物語市民（`server/game/storynpc.js`）、都市イベントエンジンの新しい段階（聞き込み `gossip`・日をまたぐ交流 `days`・面会 `meet`・演奏の聴取 `listen`・取引 `trade`・同行 `escort`・話す相手の指定 `at`）、選択による物語NPCの移住（`move`）
- EVENT 07 引退した英雄：エルムガルド。聞き込み→3日の交流→知識→記録と証言→真実→5つの結末。結末で時間割（ギルドで稽古）と会話が変わる。稽古（アーティファクト「英雄の型」）・古い武器のレシピ
- EVENT 08 旅を続ける商人：ノアは毎日、交易路の隣接都市を需要・安全（天候・火災）・最近の訪問で評価して移動。価格は街の供給・希少性・取引回数で変動、在庫は1日の数量限定。友好で希少品が増える
- EVENT 09 約束を待つ老人：ハロルドは毎夕、雨でも町の入口に立つ。セイルーンの灯台守エリクに会い、5つの結末。「連れて帰る」とエリクがマリネリアへ移住（世界共有）し、ハロルドの夕方の行動が変わる
- EVENT 10 名前を失った音楽家：楽士は7都市を日替わりで巡回し、夕方18〜22時だけ演奏。異なる4都市の曲を記録→旋律の分析→3つの結末
- EVENT 11 師匠を探す弟子：弟子リオは世界に1人のNPC冒険者として追加。教えた内容（前衛・斥候・支援）で武器と成長方向が変わり、パーティーで一緒に戦うと成長。ドラクフォードで師匠ガロウを見つけ、4つの結末。イベント後も世界で冒険者として生活を続ける
- EVENT 12 身分を隠した王族：ヴェルミオンの旅人リリィ（第二王女リリアーナ）。交流→街巡り→紋章の推理→正体→5つの結末（改革は王都の物価に影響、公務に戻ると王都の上層区で過ごす）。その後、外交書簡の依頼（繰り返し可）
- 共通：会話するとき一番近い住民に話しかけるよう改善

### 優先実装：神機の目覚め（EVENT 05）＋神機降臨（第11章）
- 二つは題材が重なるため一続きにした（`shared/data/machina.js`・`server/game/machina.js`）
- 神機の目覚め（世界共有）：遺跡の気配（時間経過・禁書庫の失伝書・グレイヴェルの「地下に眠る巨大施設」）が溜まると予兆→起動。6つの遺跡に役割の違う神機が現れる
  - 探索型は人から距離を取る／防衛型は中枢に近づく者だけを迎撃／生産型は近くの人に部品を渡す／監視型は神機が攻撃されると全機に警報／戦闘型は巡回して交戦
  - 平常時の神機は攻撃しない。攻撃すると敵対する。遺跡の周囲には野生の魔物が湧かない
- 進行：遺跡3か所の中枢を調べて役割を記録→神機制御施設（全30階）の最奥で管理型神機→5つの結末（停止／制御権回復／協力／技術提供／見守り）。最初に到達したプレイヤーの選択が世界の結末になり、以後は全遺跡に反映（停止なら神機は消え、他は平常のまま）
- 報酬：称号「神機の理解者」、神機技師の解放条件、神機工房（神機部品で正式武器種の魔導砲・魔導機械腕・ドリルランスを製作）
- 神機降臨（個人）：神機の目覚めの達成・Lv110・神機部品10個→神機デウスとの決戦→融合／封印。達成でデウス・エクス・マギアの解放条件（神機操者 熟練度8・Lv130）が満たせる

### PHASE D：探索イベント13〜18（完了）
- 共通：フィールドに調査対象を配置し、時間帯・天候・世界の状態を条件に観測する（`shared/data/explore.js`・`server/game/explore.js`）。謎解きは誤答でヒントが出て、罰則なし
- 13 地図にない図書館：4つの図書館の断片→入口の条件（知識）→真夜中→個人用の「地図にない図書館」。本は読む人の記録（達成したイベント）と世界の状態から書かれ、内容が変わると「追記あり」。未踏の領域の手掛かり、記録されない人々への伏線。3つの結末
- 14 地下に広がるもう一つの世界：異なる3ダンジョンの10階→3か所の古い標石→地下生物の調査→地下集落。交易（地上の素材と地下の素材の交換所が開く）／アンダーレルムへの抜け道（領域の発見）／秘密
- 15 幻の列車：王都街道の廃駅。真夜中（0〜3時）だけ、来る夜と来ない夜がある（黒月の前兆・夜には必ず来る）。6両（迷子の少女・楽士・宛名のない荷物・車掌・記録されない乗客・最後尾）、停車駅は毎回変わり、降りると乗った駅に戻る（ファストトラベルにしない）。出現履歴・停車履歴・車両の記録を保存
- 16 枯れない枯れ木：ユグドラシル・グローヴ。土・水・花の調査、夜だけ見える吸収、樹の内部（全10階）→再生／吸収停止／研究保存。研究後は枯れ木の花でエリクサーを作れる
- 17 動き出す石像群：3体の石像がそれぞれ夜・夕暮れ・夜明け前にだけ向きを変える。記録した視線から交点を推理（誤答でヒント）→テンペスト・リッジの隠し遺跡（全10階）。報酬は観測鏡（アーティファクト）
- 18 湖に映らない月：クリスタルウッド。晴れた夜・霧の夜・夜明け前の3つの観測で灯籠の順番が分かる→順番に灯す（間違えると消えてヒント）→湖の向こう側（全10階）。月の欠片・観測魔法・称号
