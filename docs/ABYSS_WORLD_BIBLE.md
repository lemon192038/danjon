# ABYSS ワールドバイブル

世界観・地域・都市・歴史・文化・生態系・勢力関係の基準資料。**ユーザーが指定した名称は変更しない。** 指示書で詳細が未確定の項目は「未確定」と明記し、設定を過剰に作らない（確定したら追記する）。
地理データの実体：`shared/data/world.js`（新規）、`shared/data/cities.js`（既存6都市）、`shared/data/slum.js`（既存スラム）。

## 1. 世界の基本

- ABYSS（深淵）は世界各地のダンジョンの最深部に通じる、魔力の源であり災厄の源。冒険者はダンジョンに挑み、都市は深淵から得られる資源で栄える（既存設定）。
- 世界はプレイヤーのログアウト中も、NPC・商人・組織・モンスター・国家によって動き続ける。
- 世界の裏側には「観測者」「神機文明」「第零世界」の謎があり、禁書庫・最後の住人・黒月の夜・世界の裏側の各イベントが伏線を共有する。

## 5. 既存6都市（実装済み・名称維持）

### 始まりの街ヘイヴン（辺境開拓の玄関口）

- 成立：開拓暦12年。大陸開拓の前線基地として、ダンジョン群に最も近い安全な丘に築かれた。
- 政治：開拓者評議会（町長は選挙制）／支配者：町長グレタ・ハーヴィル
- 産業：冒険者向け商売・農業・製粉／経済：冒険者の落とす金で回る小規模経済。物価は安い。
- 地理・気候：緩やかな丘陵と草原。東に翠風の平原が広がる。／温暖。春風が強い。
- 文化：新しい冒険者を祝う「門出の祭」が年に一度開かれる。
- 区画：風車広場、石垣通り、旧市街の長屋
- 歴史：深淵大陸の発見後、最初の開拓団が築いた砦が起源。大風車は開拓団長エルドが風の精霊と契約して建てたと伝わる。 → 開拓暦80年の「翠緑の古洞」魔物溢れでは砦の半分が焼失し、現在の旧市街の石垣だけが当時の名残として残る。 → 王都が冒険者の育成拠点に指定してから人口が三倍に増え、新米冒険者と彼らを相手にする商人の町になった。

### 交易港湾都市マリナ（七つの海の十字路）

- 成立：海運暦前140年。深海から湧く暖流が作る天然の良港に漁村が生まれた。
- 政治：海運会社連合による寡頭制（評議会議長＝最大海運会社社長）／支配者：議長イザベラ・ヴェルディ
- 産業：海上交易・造船・漁業・海洋研究／経済：世界一の物流量。関税収入で潤う一方、港湾労働者の賃金は低い。
- 地理・気候：南が海。湾に沿って港と倉庫街、丘の上に商人の邸宅。／温暖湿潤。夏は嵐が多く、朝は海霧が出る。
- 文化：船乗りの迷信と海神信仰。出港前に灯台へ祈りを捧げる習慣がある。
- 区画：潮見の丘（商人邸宅街）、中央市場と商館通り、大港と倉庫街、裏路地「猫の小径」
- 歴史：漁村マリナは、深海神殿から流れ出る「蒼潮」によって魚が豊富に獲れることで栄えた。 → 120年前、商人王ヴェルディが大灯台を建て、嵐の海でも夜間入港を可能にしたことで世界の交易船が集まるようになった。 → 30年前の「黒潮戦争」で私掠船団を退けた際、海運会社が自警艦隊を組織。以来、市政は海運会社連合が握っている。 → 関税の重さに耐えかねた小商人たちが密輸に走り、倉庫街の裏路地には密輸組織「海猫」の根城ができた。

### 王都セレスティア（天空を戴く王都）

- 成立：王暦元年。天から墜ちた魔力の礎石を守るため、王が城を築き人が集った。
- 政治：絶対王政＋貴族院（実権は摂政と貴族院）／支配者：国王アウレリウス七世（病床）／摂政ロデリック公
- 産業：行政・商業・金融・学術／経済：大陸最大の消費地。物価は高いが職も多い。
- 地理・気候：北の高台に王城、中央に大聖堂と行政区、南に市民街、外壁の外に下層区。／冷涼で晴天が多い。冬は雪。
- 文化：宮廷文化と騎士道。大聖堂の鐘が時を告げる。
- 区画：王城と貴族街、大聖堂区と行政街、市民街、外壁下層区
- 歴史：天空の浮遊遺跡から墜ちた「天の礎石」の上に初代王アウレリウスが城を築いたのが始まり。礎石は今も王城の地下で光を放つ。 → 三百年前の「大継承戦争」で王家が二つに割れ、勝利したセレス家が現王朝となった。敗れた分家は今も貴族院で影響力を持つ。 → 王立騎士団の創設と街道整備で大陸全土の行政の中心となり、冒険者ギルド本部もここに置かれた。 → 近年、王の病で摂政派と王女派の対立が激化し、貴族街では毒殺の噂が絶えない。下層区は再開発の名目で取り壊しが進む。

### 鉄鋼都市ヴァルカンブルク（炎と鉄の都）

- 成立：鉄暦元年。星鉄の鉱脈の上にドワーフの採掘キャンプが築かれた。
- 政治：鉱山会社と職人組合の二重支配（市長は組合推薦）／支配者：鉱山会社総裁ボルグ／組合長ヘルガ二世
- 産業：採掘・製錬・鍛冶・魔導機械／経済：武具の輸出で巨額の富。利益は鉱山会社と工房主に集中。
- 地理・気候：山脈の谷間。北に鉱山、中央に溶鉱炉と工房、南に労働者街。煙突と蒸気管が街を這う。／乾燥。煤と蒸気で空はいつも霞んでいる。
- 文化：腕前がすべて。名工の打った武具は家宝として受け継がれる。
- 区画：技師街、大溶鉱炉と工房街、労働者街、旧坑道スラム
- 歴史：ドワーフの採掘者たちが霧の高原東の山脈で「星鉄」の鉱脈を発見し、坑夫の町を開いた。 → 百年前、魔導技師ヘルガが大溶鉱炉を完成させ、星鉄を大量精錬できるようになって世界の武具の七割がここで作られるようになった。 → 二十年前の落盤事故「黒の日」で坑夫三百人が犠牲に。補償を拒んだ鉱山会社への怒りから職人組合が力を持ち、現在は組合と会社の二重支配。 → 主鉱脈の枯渇が近いという噂があり、深層採掘を巡って安全派と増産派が対立している。

### 魔導学術都市アルカナリア（叡智の湖上都市）

- 成立：叡智暦元年。魔力の湧く湖と古代の観測塔を求めて学者が集まった。
- 政治：学術共和制（七賢議会。議長は学院長）／支配者：学院長オルフェ・ミネルヴァ
- 産業：魔法研究・魔導具・錬金術・古代遺物／経済：研究費と魔導具輸出。学生街は貧しいが活気がある。
- 地理・気候：湖の中央島に大魔導塔と学院、周囲の岸辺に研究区と市場、橋で結ばれる。／霧が多く、夜は湖面に魔力のオーロラが出る。
- 文化：知識こそ力。論文の発表会は祭りのように盛り上がる。
- 区画：学院島、魔法市場、学生街、禁呪跡地
- 歴史：霧の高原の西、魔力が湧き出す「月鏡湖」の島に、古代文明の観測塔の遺跡があった。賢者ミネルヴァがそれを修復し学院を開いたのが始まり。 → 五百年前の「禁呪暴走事件」で東区画が消滅し、今も立入禁止の魔法実験区域として残っている。 → 学院は王国から自治権を得て、知識の自由を掲げる学術共和国となった。各国の魔術師が集い、魔導具の輸出で栄える。 → 最近、古代遺跡から出土した「終焉の鍵」の欠片の研究を巡り、開示派と封印派の教授が激しく対立している。

### 歓楽都市ルクスガルド（眠らない黄金の街）

- 成立：炭鉱暦30年（歓楽都市としては新暦元年）。魔石炭の鉱脈に炭鉱町が生まれ、枯渇後にカジノ資本が街を作り替えた。
- 政治：名目上は市長制。実権はヴァレン商会と黒薔薇が握る／支配者：市長カルロ・デマルコ（傀儡）／商会王ルキウス・ヴァレン／黒薔薇の首領「夫人」
- 産業：娯楽・観光・金融・（裏）闇取引／経済：巨額の金が動くが、富は北岸に集中。南岸の失業率は五割。
- 地理・気候：川が街を二分する。北岸に黄金の歓楽街と高級区、南岸に旧市街・炭鉱跡のスラム。／温暖。夜はネオンが雲を照らし、雨の日が多い。
- 文化：一夜の夢と破滅。オペラと賭博が文化の中心。
- 区画：黄金大通り（富裕・娯楽区）、時計台広場（商業・行政区）、川沿い商店街（庶民区）、旧炭鉱スラム
- 歴史：元は「灰の谷」と呼ばれた炭鉱町。百年にわたり魔石炭を掘り、王都へ送っていた。 → 五十年前に魔石炭が枯渇し、町は一度死にかけた。そこへ商会王ルキウス・ヴァレンが莫大な資本でカジノと劇場を誘致し、「新暦元年」を宣言した。 → 大通りは黄金に輝く歓楽街へ生まれ変わったが、旧炭鉱区は再開発から外され、職を失った坑夫たちが取り残されてスラムになった。 → 現在、街の利権は表のヴァレン商会と裏の犯罪組織「黒薔薇」が分け合い、市長は両者の操り人形と噂される。改革を訴える市民団体「夜明けの灯」が密かに活動している。

## 6. 既存スラム勢力（各都市のスラム深部）

- 灰鼠：貧民の互助を掲げる盗賊団。情報と盗品を扱う。
- 黒薔薇：ルクスガルドを牛耳る犯罪組織。縄張りに踏み込む者に容赦しない。
- 海猫：密輸組織。地下水路と廃港を押さえている。
- 旧坑夫組合：黒の日の生き残りたち。廃坑の奥で鉄と部品を掘り返す。
- 禁呪信奉会：禁呪の復活を目論む異端の魔術師集団。
- 夜明けの灯：スラムに灯りを取り戻そうとする互助組織。
- 屑拾い：縄張りを持たない漁り屋。誰にでも牙をむく。

## 7. 生態系（方針）

- モンスターは生息地・食性・天敵・獲物・縄張り・群れ・昼夜行動・天候反応・他モンスターとの関係を持つ（PHASE 6 以降）
- 大型モンスター（眠れる災厄の4体、古龍）は縄張り争いと周辺生態系への影響を持ち、討伐されても世界から永久には消えない
